文档 / 限制

限制与证据边界

这份清单用来防止把 fork 写成「官方 Claude Code 替代品」或「全厂商 SDK」。条目都能在仓库里找到出处。

本站不提供用户数、性能基准、采用率和 SLA。npm shield 或 GitHub star 徽章若出现在 README，也不在这里解读为社区规模。

产品形态

  • 没有浏览器应用、没有托管 Web REPL。
  • 已验证截图是 cli-dev 终端画面，品牌仍是 Free Code / Claude Code，不能当当前 wtcc 中文 UI 的宣传图。
  • 原生 Windows 未测试（CONTRIBUTING.md）。PowerShell 安装 Bun 的说明来自 README，不表示完整 Windows 支持。

Provider 与登录

  • 没有第一方 Gemini / DeepSeek / Moonshot / Z.AI / Qwen / MiniMax SDK。这些名字只出现在 id 推断与价格表。
  • OpenAI OAuth（ChatGPT / Codex 订阅登录）未实现。
  • ccswitch 登录未实现。
  • 没有「粘贴 key + 选协议」的 Ink 对话框。
  • 自动分档没有 registry anchor：可靠做法是显式 --model 或 /model。
  • relay 是否接受某个 id，以对方 /v1/models 与实际 4xx/5xx 为准，本仓库不背书可用性。

中文化未完成

378 个 key 覆盖 command / permissions / model picker / welcome / 部分 error。TODO 仍列出：

  • REPL.tsx 散落的英文字面量
  • Bash / PowerShell 选择项
  • 状态栏与调试输出

上游与许可证

  • 项目 fork 自公开可检查的 Claude Code / free-code 谱系。LICENSE 写明：ISC 覆盖 wtcc 修改与组装分发；上游代码权利仍属原作者；无担保。
  • FEATURES.md 记录大量实验 flag：有的能 bundle、有的缺文件、有的运行时要 OAuth 或原生模块。默认 bun run build 不等于「全部实验可用」。
  • VOICE_MODE 在默认构建里，但仍要 claude.ai OAuth 加本地录音（或 SoX）。
  • GrowthBook / OTel 包仍在 package.json。产品 logEvent 被 stub，不等于依赖树已删干净。

安装与发布边角

  • install.sh 仍指向 upstream free-code，不能当 wtcc 安装器。
  • TODO：bun --compile 会因 @azure/identity 动态 import 找不到模块；当前发版路径是 ship TypeScript + 要求用户本机有 Bun。
  • /update 打印 npm i -g wtcc，与包名 @unstoppablecurry/wtcc 不一致。
  • WTCC_OPENAI_FAST 已能注入 service_tier，但未在真实 ChatGPT 订阅请求上验证。

和官方 Claude Code 比什么、不比什么

README 对比表描述的是本 fork 的增量（中文、多协议、动态菜单、per-model effort、adapter 自愈、telemetry stub、开源）。它不是评测分数，也不证明官方产品「不能」做某事。官方行为以 Anthropic 文档为准。
