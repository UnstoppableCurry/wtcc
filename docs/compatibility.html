Provider 兼容性

类型 ModelProvider 只有 'anthropic' | 'openai'。其它厂商名字出现在 id 模式推断、定价表和 README 举例里，不代表本仓库实现了对应官方客户端。

权威来源：src/routing/registry.ts、src/services/api/relayModels.ts、src/services/api/adapter/normalize.ts、TODO.md。

两条请求路径

路径 如何打开 源码行为
Anthropic 协议 默认；或自备 ANTHROPIC_API_KEY。也可把 ANTHROPIC_BASE_URL 指到 relay 的 Anthropic 入口。 /login 走 ConsoleOAuthFlow（Anthropic OAuth）。凭证目录按上游惯例写到 ~/.claude/。
OpenAI 兼容协议 CLAUDE_CODE_USE_OPENAI=1，并设置 OPENAI_BASE_URL / OPENAI_API_KEY。 claude-openai.ts + adapter/normalize.ts 把内部消息转成 OpenAI chat/completions 形态；并行 tool_calls 按 stream index 组装。

Relay 与 /model 菜单

wtcc-zh.sh 默认把 OpenAI 基址设为 https://convertmodel.net，Anthropic 基址设为 https://convertmodel.net/anthropic。这是启动脚本里的默认 relay 举例，不是「只支持这一家」的硬编码产品声明。

当 CLAUDE_CODE_USE_OPENAI 为真，fetchRelayModels() 会请求 {OPENAI_BASE_URL}/v1/models，过滤掉 dated snapshot、preview / realtime / audio、gpt-3.5、gpt-image-* 等，再写入 /model 缓存。未开 OpenAI 路径时，这段探测是 no-op，菜单仍走上游 Anthropic bootstrap。

/diagnose-relay 打印当前 env flag 与 key 掩码，并对 OpenAI base 做一次 GET /v1/models（8 秒超时）。它不调用 /chat/completions，因此不是一次付费对话探测。

Model id：不维护支持清单

MODEL_REGISTRY 为空。注释写明：用户传入的 id（例如 gpt-5.5、gemini-3、kimi-k2-thinking、deepseek-v4-pro、glm-4.6、MiniMax-M1、qwen-max-latest）一律放行；能不能用由 relay / API 在请求时决定。

inferProvider 的规则只有一条分叉：

  • id 匹配 /^claude-/i → anthropic
  • 其余全部 → openai

因此 Gemini / DeepSeek / Kimi / GLM / Qwen / MiniMax 在本仓库里都被当成 OpenAI 兼容 id 做上下文窗口、vision、effort、价格的模式推断，供 /cost 与菜单描述使用。推断错了不会在发请求前拦截。

计价表覆盖的家族

src/routing/pricing.ts 为下列家族写了公开标价近似值（注释写明 2026 年公开页、球公园数字），供 relay 路径的 cost-tracker 使用：

  • OpenAI GPT-5 / o-series / GPT-4.x
  • Anthropic Claude
  • Google Gemini 若干 id
  • DeepSeek、Moonshot / Kimi、Z.AI GLM、Alibaba Qwen、MiniMax

未知 id 回退到更粗的模式价。Anthropic 原生平走 utils/modelCost.ts 的 MODEL_COSTS（含 cache 价）。这不是「这些厂商都已签约认证」的证明。

OpenAI adapter 自愈范围

patchOrphanToolCalls 会在历史被 compact 丢掉 tool 结果时，给未匹配的 tool_call_id 插入空的 role:'tool' 消息，避免 OpenAI 返回 “No tool output found”。 并行 tool_calls 按 stream 的 delta.tool_calls[i].index 组装。真实 token usage 从 OpenAI / Codex 完成事件回填（见 claude-openai.ts 与 codex-fetch-adapter.ts）。
