安装与使用

这是终端程序。安装后在 shell 里运行 wtcc，不会出现网页版 REPL。CONTRIBUTING 写明开发环境按 macOS / Linux / WSL2 验证，原生 Windows 未测试。

前置：Bun

package.json 要求 bun >= 1.3、node >= 20。 npm 全局包提供的是 Node shim（bin/wtcc.cjs），shim 找到 bun 后再 bun run src/entrypoints/cli.tsx。没有 Bun 会退出并打印安装提示。 

curl -fsSL https://bun.sh/install | bash

Windows PowerShell（README）：

powershell -c "irm bun.sh/install.ps1 | iex"

安装方式

npm 全局（README 主推）

npm install -g @unstoppablecurry/wtcc
wtcc --help
wtcc --version

若提示 command not found，把 npm bin -g 或 ~/.bun/bin 加进 PATH。

bun 全局

bun add -g @unstoppablecurry/wtcc

从源码

git clone https://github.com/UnstoppableCurry/wtcc.git
cd wtcc
bun install
bun run build      # 产出 ./cli
./wtcc-zh.sh       # 中文 + 默认 relay 环境

不要用仓库根目录的 install.sh 当官方安装器：它仍克隆 paoloanzn/free-code 并链接 free-code 命令，是上游残留。

鉴权（按 README 优先级）

1. Anthropic OAuth

wtcc /login

浏览器走 Anthropic 账户；token 写入 ~/.claude/。

2. Relay key

export WTCC_RELAY_KEY="sk-relay-xxxxxxxx"
./wtcc-zh.sh

等价的手动导出（README）：

export FREE_CODE_MULTI_PROVIDER_NORMALIZED=1
export CLAUDE_CODE_USE_OPENAI=1
export OPENAI_BASE_URL="https://convertmodel.net"
export OPENAI_API_KEY="sk-relay-xxxxxxxx"
wtcc --model gpt-5.5

wtcc-zh.sh 读 key 的顺序：WTCC_RELAY_KEY → FREE_CODE_RELAY_KEY → OPENAI_API_KEY → ANTHROPIC_AUTH_TOKEN。缺 key 会直接退出。脚本还会 exec bun run ./src/entrypoints/cli.tsx --dangerously-skip-permissions。

3. 原生 Anthropic API key

unset CLAUDE_CODE_USE_OPENAI
unset OPENAI_BASE_URL
export ANTHROPIC_API_KEY="sk-ant-xxxxxxxx"
wtcc --model claude-opus-4-7

使用例子

# 交互 REPL（中文）
FREE_CODE_LANG=zh-CN wtcc

# 源码开发
bun run dev

# 单次提问（wtcc-zh.sh 支持 -p）
./wtcc-zh.sh -p "列出当前目录的 TypeScript 入口"

# 解释最近一次路由
# 在 REPL 输入：
# /why-this-model

# 探测 relay（只 GET /v1/models）
# /diagnose-relay

本仓库强调的斜杠命令

上游 Claude Code 还有大量命令登记在 src/commands.ts。下表只列 README 与 wtcc 增量实现能对上的部分。

命令 证据中的行为
/model Ink model 菜单；OpenAI 路径下合并 relay /v1/models
/effort low|medium|high|max|xhigh|auto；按 model 过滤档位；CLAUDE_CODE_EFFORT_LEVEL 优先
/why-this-model 读内存里的路由决策环（routing/decisionLog.ts）
/diagnose-relay 打印 flag / 掩码 key，并探测 OpenAI /v1/models
/update 只读查 npm registry（24h 磁盘缓存）。源码打印的升级命令是 npm i -g wtcc，与 scoped 包名不一致；实际安装请用 @unstoppablecurry/wtcc
/cost 当前会话花费；relay 走 routing/pricing.ts
/login Anthropic OAuth，不是 OpenAI OAuth
/version /help 版本与命令列表
/curry wtcc 专属 drawille 动画命令
/upgrade 上游 Anthropic Max 套餐流程，不升级 wtcc 本身

环境变量

变量 作用（README / 脚本）
ANTHROPIC_API_KEY / ANTHROPIC_AUTH_TOKEN Anthropic 凭证；后者给 relay Bearer
ANTHROPIC_BASE_URL / ANTHROPIC_MODEL 覆盖 Anthropic 端点与默认 model
OPENAI_API_KEY / OPENAI_BASE_URL OpenAI 或兼容 relay
CLAUDE_CODE_USE_OPENAI=1 走 OpenAI 协议路径
FREE_CODE_MULTI_PROVIDER_NORMALIZED=1 开启 normalised 多 provider 路由
FREE_CODE_LANG zh-CN / en-US；未设则看 LANG
WTCC_RELAY_KEY wtcc-zh.sh 读取的 relay 凭据
WTCC_OPENAI_FAST=1 提示 Codex 请求带 service_tier: "fast"（TODO：未在真 ChatGPT 订阅上验证）
CLAUDE_CODE_EFFORT_LEVEL 默认 effort，覆盖会话设置
DISABLE_AUTOUPDATER=1 关闭上游 auto-updater

FREE_CODE_* 是历史命名空间，为兼容保留。

从源码构建

命令 输出
bun run build ./cli 生产构建
bun run build:dev ./cli-dev，带 dev 时间戳
bun run build:dev:full ./cli-dev，打开当前实验 feature 集合
bun run compile ./dist/cli；TODO 记录 bun --compile 在 Azure 动态 import 上会坏
bun run dev 直接跑 TypeScript 入口
bun test tests/ 现有测试
